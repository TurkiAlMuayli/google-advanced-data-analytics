# Google Advanced Data Analytics professional Certificate

Case studies, projects, and practice activities completed while working through Google's Advanced Data Analytics Professional Certificate (Coursera). Each end-of-course project follows a fictional client through the full analytics workflow: data cleaning, exploratory analysis, statistical testing, and predictive modeling.

## Structure

- **`End-Of-Course-Projects/`** — the graded case studies, each tied to one client, updated as later courses add new stages (EDA, hypothesis testing, regression, classification)
  - `Automatidata/` — NYC Taxi and Limousine Commission trip data
  - `TikTok/` — claims classification for user-submitted videos
  - `Waze/` — user churn analysis
- **`Practice-Activities/`** — standalone exercises using separate datasets to practice a specific technique, not part of the three case studies above
  - `data_exploration_and_cleaning/` — activities on exploring, validating, and cleaning data
  - `statistics/` — statistics activities
  - `regression/` — regression activities
  - `machine_learning/` — machine learning activities
- **`Tableau/`** — Tableau work from the certificate

## Tools

Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn, XGBoost, Tableau, Jupyter Notebook
