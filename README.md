# Google Advanced Data Analytics

Case studies and projects completed while working through Google's Advanced Data Analytics Professional Certificate (Coursera). Each end-of-course project follows a fictional client through the full analytics workflow: data cleaning, exploratory analysis, statistical testing, and predictive modeling.

## Structure

- **`end-of-course-projects/`** — the graded case studies, each tied to one client, updated as later courses add new stages (EDA, hypothesis testing, regression, classification)
  - `automatidata/` — NYC Taxi and Limousine Commission trip data
  - `tiktok/` — claims classification for user-submitted videos
  - `waze/` — user churn analysis
- **`practice-activities/`** — standalone exercises using separate datasets to practice a specific technique, not part of the three case studies above
